# AI Resume Reviewer

An AI-powered web app that analyzes resumes against a target job role and provides:
- Overall resume score
- Strengths & weaknesses
- Missing skills
- ATS suggestions
- Formatting/content improvements

## Tech Stack
- Frontend: React + Vite + Tailwind CSS
- Backend: Python + FastAPI
- Database: MongoDB Atlas
- AI: TBD
